# autowash
## Описание проекта
CarWash API — это backend-приложение на **Django REST Framework** для управления автомойками, сотрудниками, услугами и клиентскими машинами.  
Проект включает **JWT-аутентификацию**, подтверждение email, сброс и восстановление пароля, а также фильтрацию и агрегацию данных по заказам.

## Используемые технологии
- **Python 3.11**  
- **Django 5** + **Django REST Framework**  
- **SimpleJWT** — для access и refresh токенов  
- **PostgreSQL** — основная база данных  
- **Redis** — кэширование запросов  
- **django-filter** — фильтрация данных  
- **drf-yasg** — документация Swagger  
- **Docker & docker-compose** — контейнеризация

## Основной функционал

### 1. Управление данными автомойки
- **WashStationViewSet** — управление автомойками, доступ только своим пользователям.  
- **EmployeeViewSet** — CRUD для сотрудников, с фильтрацией по имени.  
- **ServiceViewSet** — управление услугами, привязанными к конкретной автомойке.  
- **CarViewSet** — хранение информации о машинах клиентов с возможностью:
  - фильтрации по времени въезда,
  - получения общей статистики (все время / сегодня / по фильтрам),
  - кеширования результатов для оптимизации.

### 2. Аутентификация и управление пользователями
- **RegisterView** — регистрация нового пользователя с валидацией номера телефона (формат 992XXXXXXXX).  
- **ConfirmEmailView** — подтверждение email через токен.  
- **LoginView** — вход по email и паролю, возвращает **access** и **refresh** токены.  
- **LogoutView** — выход, аннулирует refresh-токен.  
- **ForgotPasswordView** — запрос на сброс пароля с отправкой письма.  
- **ResetPasswordView** — установка нового пароля через токен.

### 3. JWT-аутентификация
- При входе пользователь получает **access** и **refresh** токены.  
- **access token** используется для авторизации в API-запросах.  
- **refresh token** позволяет обновлять access без повторного входа.  
- Logout заносит refresh в blacklist.
